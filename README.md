# About this repository

Go is a small, but handy and safe language, which is why I want to learn it.

This repository hosts the source code while I work through the book *Learning Go*.

**Note**: The reading of the first ten chapters of the book *Learning Go* is already enough for me to have encountered a substantial portion of the language's central design philosophy. But for a mix of a few reasons, I don't find some of the abstractions offered by the language intellectually compelling. And plus the fact it's not quite centrual to my area of interests, maybe I will give it a pause there, and resume learning it when Go's language features offer me genuinely interesting benefits for a project that I will perhaps work on.
